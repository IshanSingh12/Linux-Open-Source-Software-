# Open Source Audit: Python
**Student:** Ishan Singh
**Course:** Open Source Software (NGMC)  
**Software Audited:** Python (PSF License)

## 1. Project Overview
This repository contains the technical components for the OSS Capstone Project. It includes a series of Bash scripts designed to audit the Python environment on a Linux system, demonstrating the transparency and accessibility of open-source tools.

---

## 2. Problem Statement
Most users don’t know what’s happening inside their system — which packages are installed, how much space they take, or what updates have occurred. This lack of visibility can lead to confusion and poor system management.

This project solves that by providing a set of simple scripts that analyze and display important information about the Python setup on a system.

---

## 3. Features
1) Check system details and environment
2) View installed Python packages and versions
3) Analyze disk usage of Python files
4) Review logs for Python-related updates
5) Generate a personal open-source manifesto

---

## 4. How to run
Prerequisites: Linux system with Bash installed

1) Clone Repository: git clone https://github.com/IshanSingh12/Linux-Open-Source-Software-
2) Navigate to Project: cd Linux-Open-Source-Software-
3) Make Scripts Executable: chmod +x *.sh
4) Run: Execute any script using: ./script_name.sh

---

## 5. Included Scripts
1. `1_system_identity.sh`: Reports system hardware and OS licensing.
2. `2_package_inspector.sh`: Audits installed Python packages and versions.
3. `3_disk_auditor.sh`: Analyzes the file footprint of Python in `/usr/lib`.
4. `4_log_analyzer.sh`: Reviews system logs for Python-related updates.
5. `5_manifesto.sh`: An interactive script generating a personal FOSS manifesto.
